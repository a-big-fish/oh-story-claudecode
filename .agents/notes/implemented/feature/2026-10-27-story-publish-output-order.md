# Agent Note: 发布资料的字段顺序与标签分行

Status: implemented

## Problem

发布资料没有固定展示顺序，来源说明可能排在书名之前，阅读标签和内容标签的多个子字段挤在同一行，不便作者对照平台填写。

## Decision

回复和落盘使用相同顺序：元信息后立即显示书本名称，再列基础字段、封面、阅读标签、内容标签、作品简介、待作者按照发布界面核实的内容、待平台核实、来源说明。两组标签的各子字段独立成行，保留已确认值与建议的区别。封面交接见[封面模式确认](2026-10-27-story-publish-cover-handoff.md)。

旧文件更新时也按新结构重排。落盘后运行 skill 内的只读格式检查，验证元信息、首标题、七个二级标题顺序、封面字段和标签独立分行；提示词代码块中的标题不作为文档小节。不通过时修正后再报告完成。无执行能力时读取文件逐项核对，并披露未运行自动检查。

## Alternatives considered

保留通用字段表格可以灵活容纳不同平台，但无法保证书名优先和标签分行，因此为当前发布资料明确规定顺序。

## Consequences

作者可以按固定位置快速找字段并复制填写；模板增加少量必读文本，需要同步登记加载预算。已有文件的手工内容仍须保留。
