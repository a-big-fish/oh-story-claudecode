# Agent Note: 短故事发布资料与跨平台回归

Status: implemented

## Problem

短故事已有独立发布表单截图，但资料模板和检查器仍只支持长篇标签，格式检查也未接入 CI。

## Decision

将获准入库的六张裁剪图与 102 个分类候选登记为 2026-10-28 资料；按作品类型区分模板及只读检查，短故事检查分类分栏、候选归属及包含主分类的总数上限八项。准备文件允许留空，主分类缺失仍须列待办，不冒充提交就绪。新增 16 项永久回归测试并接入 Linux、Windows、macOS CI，包含真实 CLI 临时文件读写边界测试；远端结果须推送后另行确认。

## Alternatives considered

沿用长篇模板可减少代码，但会误用阅读标签、内容标签及签约模式。仅手工验证能快速确认样例，但不能阻止后续回归，因此保留自动测试。

## Consequences

发布准备覆盖短故事当前可见字段；作者补充确认 Web 发布入口为 short-manage、账号 Lv.2、作品为未发布草稿，仅适用于本次样本。截图不能证明留空拦截或提交成功，其他账号条件和实际边界仍须列待核实。新增参考资料按需加载，不增加准备工作的浏览器依赖。
