# Agent Note: 发布资料与封面模式确认

Status: implemented

## Problem

发布准备只在作者主动要求封面提示词时调用封面 skill，书名和简介定稿后没有主动确认封面模式，提示词也未固定写进发布资料。

## Decision

书名和简介确认后检测当前会话的实际生图能力，并请作者确认直接生图、仅提示词或暂缓。调用 story-cover 时传递已确认事实和模式；两种交付都把完整提示词写入阅读标签之前的“封面”小节，图片仅在实际生成并保存后记录路径。能力缺失、失败或入口不可用时保留待办，不阻塞其他字段。

## Alternatives considered

按模型名称自动选择生图能减少询问，但不能证明当前会话工具可用，也未取得作者对生图的确认，因此依据会话能力并保留模式选择。

## Consequences

发布资料包含可复用的封面提示词和明确状态；需要同步输出格式校验、封面输入交接与封面参考资料的叠加预算，保留 OpenClaw 的发现门槛。
