# Agent Note: 番茄账号与三阶段证据补充

Status: implemented

## Problem

旧适配未确认最小建书的准确模式字段，也缺少账号资格和长短篇分阶段依据。作者补充了 2026-10-28 核查报告，但报告仍含第三方转述与明确未知项。

## Decision

将补充报告整理为带元信息的 Markdown 参考，保留报告中的证据层级和限制。长篇最小建书改为书名与签约模式必填；短故事发布单独记录，不前移到创建草稿。保留 2026-10-25 标签截图的有效范围，阶段报告更新日不冒充标签更新日或独立登录核验。

V1.2 补记长篇和短故事 Web 管理入口，按 E01–E08 跟踪具体表单、账号条件、原图与操作结果缺口；入口可用性不等同字段或提交校验通过。

## Alternatives considered

把整份报告当作已核实规则能简化校验，但会将公开转述和未知条件提升为平台事实，因此按来源及阶段分别记录。

## Consequences

资料准备可使用新增账号与阶段基线，但长篇补资料、章节发布及短故事草稿条件仍保留缺口；需要新增参考文件并计入读取预算。
